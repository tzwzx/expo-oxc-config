# fixtures

共有設定の**ツールチェーンが壊れていないこと**を確かめるためのサンプルコード。
`bun verify` がここに oxlint / oxfmt を当て、下記を検査する。

- 設定が読める（ultracite の export 構成やルール名が変わって壊れていない）
- 3つの JS プラグイン（github / sonarjs / react-doctor）が実際にルールを供給している
- `ignorePatterns` の再宣言が効いている
- `src/**` と `jest.setup.ts` の override が効いている
- 共有設定で off にしているルールが実際に発火しない

**指摘の件数や内容は固定していない。** ルールの追加・改名・挙動変更は許容し
（アプリ側で追従すればよい）、「まともに動かない状態のまま更新してしまう」ことだけを防ぐ。

fixture は「本来なら指摘されるコード」をわざと書いている。lint がきれいに
通ることを目指す場所ではないので、ここのコードを"直して"はいけない。
